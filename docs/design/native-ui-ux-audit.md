# Clipco native UI/UX audit

2026-10-10, Asia/Manila. Requested by the creator using `emil-design-eng`.

The sidebar/browser/inspector structure is the right foundation. The largest improvements are predictable navigation, compact footage browsing, clear destinations, and feedback that arrives immediately. Keep system controls and restrained motion. This is an audit and proposed work order, not an implementation or a claim of Apple-level performance.

## Recommended change sequence

1. Bound thumbnails; connect search selection to Segment playback; correct picker destination presentation; fix grid navigation/focus. These are the first practical gains.
2. Align role/review filters with Segment data; add safe immediate feedback for metadata edits; distinguish loading, empty, and updating states.
3. Reorder inspector content and add disclosures, then improve recovery/queue copy, transcript following, and state restoration.
4. Run focused native verification before decorative motion work. No redesign of the approved three-column workflow is needed.

## Motion and responsiveness contract

Keep selection, search focus, shortcuts, and keyboard navigation immediate. Let standard SwiftUI/AppKit controls provide press, hover, sheet, and popover behavior. The skill's CSS scale/blur examples should not be copied wholesale into native macOS controls. Reserve short, interruptible motion for mouse-driven disclosure or state changes that need continuity; honor Reduce Motion. Avoid card staggering and bouncing controls in this frequently used browser.

Keep media decoding and inference off the main actor. FrameImage already decodes asynchronously, SourceAccess checks off the main actor, and worker calls are asynchronous. Add bounded thumbnail decoding/cache only if profiling supports it; avoid claiming smoothness from those architecture choices alone. Measure selection/scroll/seek responsiveness while processing real footage. Investigate the previously recorded 290 ms main-thread stall with Instruments before promising a particular frame rate.

## Verification for the first fixes

- Fresh native build with mixed orientation footage; cards keep equal thumbnail bounds and reveal labels at minimum supported window size.
- Select a nonzero search match; Space, double-click, and ⌘↓ each start at that match. Escape restores browser focus and selection.
- In grids with different column counts, all arrow directions and Shift selection behave spatially; selection stays visible after scrolling.
- Open library import with and without a previous Project: destination text agrees with the queued job. Navigation during an import cannot retarget the job.
- Navigate between clips and Projects during note saves; each note persists only to its original Project membership and failures preserve the draft.
- Check light/dark appearance, Increase Contrast, Reduce Motion, VoiceOver, Full Keyboard Access, and long filenames at the minimum window size.
- Review queued/paused/interrupted/waiting states on a fresh build; measure UI response during a real job without altering original footage.

Tests were not rerun because this audit changes documentation only. Existing worker tests and automation evidence do not substitute for native interaction checks of these fixes.
