# Separate Project context from library reuse

The creator accepted separate retrieval scopes: Project footage context retains A-roll, corrections, and repeated takes, while reuse discovery considers eligible B-roll across the indexed Footage library. A-roll stays project-bound as a product rule; useful cross-project B-roll remains eligible with its origin preserved. This broadens reuse without losing the main narrative evidence needed by an editing agent or treating every indexed recording as reusable.
