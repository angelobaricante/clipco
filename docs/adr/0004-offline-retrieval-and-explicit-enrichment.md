# Keep library retrieval local and upgrade analysis explicitly

The creator accepted emotional tone as saved visual interpretation based on sampled evidence, exposed through app and MCP library retrieval with preserved source provenance. Existing footage remains usable while a creator explicitly queues enrichment; absent tone is Not analyzed rather than neutral, and valid cached evidence is reused where possible. This retains the existing offline, read-only retrieval boundary and avoids making every search or app launch initiate expensive inference or silently weaken old evidence.
