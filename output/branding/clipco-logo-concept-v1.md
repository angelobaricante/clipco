# Clipco logo concept v1

Generated with the built-in image generation tool. Concept only; not installed in the app.

## Prompt

Use case: logo-brand. Create one polished original logo for Clipco, a native Mac app that organizes raw footage and prepares searchable context for editing agents. The user reference is the Cursor logo shown in the conversation: use its bold monochrome geometric simplicity, visual weight, angular facets and clever negative space as stylistic inspiration. Design a distinct Clipco identity: a chunky angular letter C constructed as a folded ribbon or open geometric frame, with a subtle rectangular footage-frame cutout. Strong recognizable C silhouette with an open right side; elegant deliberate geometry, minimal number of facets, carefully balanced proportions. Do not reproduce Cursor's hexagonal cube or cursor arrow. Solid near-black mark, no gradients, no shadows, no textures. Below the mark place the exact word 'Clipco' in refined bold modern sans-serif, correctly spelled with capital C, comfortable spacing. Single centered vertical lockup, ample padding, icon prominent, wordmark subordinate. Transparent background with genuine alpha. No mockups, no decorative scenes, no extra labels, no borders, no watermark. Designed to remain legible as a small app brand symbol.
